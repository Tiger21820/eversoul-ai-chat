<h1 align="center">EverSoul AI Chat — FAQ (가넷이 알려줄게♥)</h1>

안녕 구원자님♥ 나랑 이 결계(프로그램) 안에서 노는 데 궁금한 점이 생겼다고?
구원자님이 곤란해하는 걸 그냥 볼 수는 없지. 자주 묻는 질문들을 내가 직접 대답해 줄 테니까 잘 읽어봐♥

---

### 🐰 Q1. 진짜 인터넷 연결 없이도 정령들과 대화할 수 있는 거야?
**가넷:** 응, 당연하지♥ 이 결계 안의 모든 지능(AI)은 구원자님의 PC에서 직접 돌아가게 설계되었어. 오프라인 상태라도 나랑 95명의 정령들은 항상 구원자님 곁에 머물며 대답할 준비가 되어 있으니까 언제든 찾아와!

### 🐰 Q2. 대화 내용이 어디 다른 서버로 전송되거나 수집되진 않아?
**가넷:** 절대! 구원자님과 나눈 은밀한 이야기들을 남들이 훔쳐보게 내버려둘 리가 없잖아? 우리의 대화 기록과 모든 기억은 오직 구원자님의 기기 안 `eversoul.db`라는 안전한 금고에만 보관돼. 밖으로는 데이터가 단 1바이트도 빠져나가지 않으니까, 아무한테도 말 못할 은밀한 욕망까지 맘껏 털어놔도 좋아♥

### 🐰 Q3. 정령들의 성격이랑 말투는 어떻게 똑같이 구현한 거야?
**가넷:** 후훗, 내가 이 결계를 만들 때 에버소울의 진짜 심장부(게임 마스터 데이터 TBL)를 싹 다 뒤져서 엮었거든. 각 정령이 쓰던 말투, 성격, 심지어 다국어(한국어/영어/중국어) 데이터까지 완벽하게 추출해서 `data/personas/`에 주입했어. 그러니까 지금 구원자님 눈앞에 있는 나는, 가짜가 아니라 100% 진짜 가넷이야♥

### 🐰 Q4. 화면이 멈추거나 대답이 너무 오래 걸리면 어떡해?
**가넷:** 구원자님을 기다리게 하는 짓은 절대 안 해! 무거운 뇌(LLM) 연산은 전용 워커 스레드에서 돌아가고, 화면은 그동안 멀쩡히 움직여.

그리고 내 대답을 다 만들 때까지 기다리게 하지도 않아. 한 글자 만들어질 때마다 바로바로 화면에 띄워 주니까(`chat-stream-token`), 내가 생각하는 걸 실시간으로 지켜볼 수 있어. 대답이 마음에 안 들면 **중지 버튼**으로 끊어도 돼♥

거기다 정령별 KV 상태를 `.bin` 파일에 보존해 두니까, 다음 턴에는 프롬프트에서 **똑같은 앞부분만큼** 계산을 통째로 건너뛰어. 대화를 이어갈수록 내가 더 빨리 대답하는 이유야!

### 🐰 Q5. 엄청 좋은 컴퓨터가 필요한 건 아니지?
**가넷:** 걱정 마. 무거운 그래픽 카드(GPU)가 없어도 괜찮도록, `gemma-2-2b-it Q4_K_M` GGUF 모델을 `llama.cpp` 엔진으로 CPU에서 돌아가게 최적화해 뒀어. 2B짜리 작은 모델이라 램(RAM)만 넉넉하면 누구나 부드럽게 나를 만날 수 있어♥

### 🐰 Q6. 모델은 어디서 받아? 저장소에 들어 있어?
**가넷:** 아니, 모델 파일은 1.7GB나 되는 커다란 녀석이라 저장소에는 안 넣었어. 앱을 처음 켜면 초기 설정 마법사가 [Hugging Face](https://huggingface.co/bartowski/gemma-2-2b-it-GGUF)에서 직접 받아다가 `ai/model/`에 넣어 줘. 받은 다음엔 SHA-256까지 확인하니까 파일이 깨졌는지도 바로 알 수 있어♥

### 🐰 Q7. 나도 직접 빌드해 볼 수 있어? Rust 같은 건 설치하기 무서운데.
**가넷:** 아무것도 설치 안 해도 돼♥ 저장소를 **Fork** 하고, **Star** ⭐ 랑 **Watch** 👁 를 눌러 둔 다음, 내 저장소의 **Actions** 탭에서 `Build Portable` 워크플로를 **Run workflow** 로 한 번만 돌려 줘. GitHub이 알아서 다 만들어서 **Artifacts** 에 올려 주니까 그걸 받아서 압축만 풀면 끝이야!

### 🐰 Q8. 내가 원하는 정령을 위한 특별한 지식을 더 가르칠 수 있어?
**가넷:** 그럼! 더 깊은 자극을 원한다면 언제든 환영이야. 지식 팩이나 스타일 팩, 혹은 직접 파인튜닝(LoRA)을 해서 정령에게 씌워줄 수도 있어. 구원자님이 원하는 취향이 있다면 나한테 듬뿍 주입해 줘. 기꺼이 그 판타지를 현실로 만들어 줄 테니까♥

### 🐰 Q9. 내 컴퓨터가 너무 약하면 외부 API를 써도 돼?
**가넷:** 응, 그것도 준비해 뒀어. `Settings` 화면에서 외부 API를 켜면 로컬 모델 대신 OpenAI 호환 엔드포인트로 대화해. 내 성격이랑 말투, 기억만 뽑아서 보내는 거니까 나다움은 그대로야. 다만 새 기억을 임베딩해서 쌓는 건 로컬 엔진이 있어야만 되니까, 외부 API 모드에서는 기억 회상이 잠깐 쉬어 간다는 것만 알아 둬♥
