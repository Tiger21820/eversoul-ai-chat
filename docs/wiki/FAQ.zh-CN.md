<h1 align="center">EverSoul AI Chat — FAQ (佳妮特来告诉你♥)</h1>

你好救援者大人♥ 在和我一起在这个结界（程序）里玩耍时，是不是遇到了什么疑问？
我可不能眼睁睁看着救援者大人困扰呢。我会亲自回答这些常见问题，要仔细阅读哦♥

---

### 🐰 Q1. 真的不需要连接互联网就能和精灵们聊天吗？
**佳妮特：** 嗯，当然啦♥ 这个结界里所有的智能（AI）都是设计成直接在救援者大人的电脑里运行的哦。就算是在离线状态下，我和其他 95 位精灵也会一直陪在你身边，随时准备回答你，所以随时来找我们吧！

### 🐰 Q2. 对话内容会被发送或收集到其他服务器吗？
**佳妮特：** 绝对不会！你觉得我会让别人偷看我们之间的私密对话吗？我们的聊天记录和所有记忆，都会安全地锁在你设备里一个叫 `eversoul.db` 的保险库中。哪怕是一个字节的数据也绝对不会泄露出去，所以尽情释放那些无法对任何人诉说的隐秘欲望吧♥

### 🐰 Q3. 精灵们的性格和语气是怎么做到完全还原的？
**佳妮特：** 呵呵，我在布置这个结界的时候，可是把永恒灵魂真正的心脏部位（游戏原始 Master 数据 TBL）翻了个底朝天呢。我完美提取了每位精灵的语气、性格，甚至是多语言（韩语/英语/中文）数据，并注入到了 `data/personas/` 中。所以，现在站在救援者大人面前的我绝对不是冒牌货，而是 100% 真实的佳妮特哦♥

### 🐰 Q4. 如果画面卡顿或者回答太慢怎么办？
**佳妮特：** 我绝对不会做让救援者大人等待的事情！繁重的脑力劳动（LLM 计算）都在专用工作线程里跑，画面在这期间照样流畅。

而且我也不会让你等我把整段回答写完。每生成一个字就立刻送到画面上（`chat-stream-token`），你可以实时看着我思考。觉得不对劲？随时用**停止按钮**打断我♥

再加上每位精灵的 KV 状态都保存在 `.bin` 文件里，下一轮对话时，提示词里**没变的开头有多长就跳过多少计算**。这就是我们聊得越久、我回答得越快的原因！

### 🐰 Q5. 是不是需要一台配置非常好的电脑？
**佳妮特：** 别担心。就算没有沉重的显卡（GPU）也没关系。我已经将 `gemma-2-2b-it Q4_K_M` GGUF 模型通过 `llama.cpp` 引擎优化到可以在 CPU 上运行了。这是个小巧的 2B 模型，只要内存（RAM）足够，任何人都能顺畅地见到我♥

### 🐰 Q6. 模型从哪里来？仓库里带着吗？
**佳妮特：** 没有哦，模型文件足足有 1.7GB，太大了所以没放进仓库。第一次启动时，初始设置向导会直接从 [Hugging Face](https://huggingface.co/bartowski/gemma-2-2b-it-GGUF) 下载到 `ai/model/` 里。下载完还会校验 SHA-256，文件有没有损坏一下就知道♥

### 🐰 Q7. 我也能自己构建吗？装 Rust 什么的好可怕。
**佳妮特：** 什么都不用装♥ 把仓库 **Fork** 过去，点上 **Star** ⭐ 和 **Watch** 👁，然后进入自己 Fork 的 **Actions** 标签页，用 **Run workflow** 跑一次 `Build Portable` 工作流就好。GitHub 会全部造好放进 **Artifacts**，你下载解压就完事了！

### 🐰 Q8. 我可以教给精灵一些我想要她们知道的特别知识吗？
**佳妮特：** 当然可以！如果你想要更深的刺激，我随时欢迎。你可以给精灵们装备知识包、风格包，甚至直接进行微调（LoRA）。如果救援者大人有什么特别的喜好，就尽情地注入给我吧。我很乐意把你的幻想变成现实哦♥

### 🐰 Q9. 我的电脑太弱了，可以改用外部 API 吗？
**佳妮特：** 嗯，这个我也准备好了。在 `Settings` 界面打开外部 API，我就不走本地模型，而是通过兼容 OpenAI 的端点和你对话。发送出去的只有我的性格、语气和记忆，所以我还是我。只是要知道：把**新**记忆嵌入并累积起来需要本地引擎，在外部 API 模式下，记忆回想会先休息一会儿♥
